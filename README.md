# Bitter - A Social Media App

Bitter is a modern social media application built using Vite, React, and TypeScript. It provides users with a platform to connect, share, and engage with others.

## Features

- User authentication and profile management
- Post creation, editing, and deletion
- Like, comment, and share functionality
- Responsive design for mobile and desktop

## Tech Stack

- **Frontend**: React, TypeScript
- **Build Tool**: Vite
- **Styling**: Ant-design & CSS
- **State Management**: Tanstack Query

## Installation

1. Clone the repository:

```bash
git clone https://github.com/mohitpuri-codes/bitter.git
cd bitter
```

2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open the app in your browser at `http://localhost:5173`.

## Scripts

- `npm run dev`: Start the development server
- `npm run build`: Build the app for production
